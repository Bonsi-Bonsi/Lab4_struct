# Лабораторная работа: Сервис сокращения ссылок (URL Shortener)

## Цель работы
Реализовать упрощённый сервис сокращения ссылок с возможностью добавления, поиска и просмотра всех сокращённых ссылок через консольное меню.

## Описание задачи
Сервис должен уметь:
- Сохранять длинную ссылку
- Выдавать ей короткий код (автоматическая генерация)
- По короткому коду возвращать исходную длинную ссылку

### Пример работы
- Длинная ссылка: `https://example.com/articles/python-basics`
- Короткий код: `a1b2`
- Результат хранения: `a1b2 -> https://example.com/articles/python-basics`

## Реализованные методы

### Класс URLShortener
- `__init__()` - конструктор, создаёт пустой словарь для хранения ссылок
- `_generate_code()` - генерация уникального короткого кода (4 символа из букв a-z и цифр 0-9)
- `add_url(long_url)` - добавить новую ссылку
- `get_url(code)` - получить длинную ссылку по короткому коду
- `check_code(code)` - проверить существование короткого кода
- `get_all_urls()` - получить все пары ссылок (в порядке добавления)
- `show_all_urls()` - вывести все пары ссылок на экран
